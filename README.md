# MenciaVanderSaignaIlustration
Portfolio web de ilustración (HTML/CSS/JS estático, sin build). Abre `index.html` o sirve la carpeta (`python3 -m http.server`).

- `css/styles.css`: paleta de colores, tamaño de imagen principal, transiciones (variables comentadas arriba).
- `js/config.js`: Google Sheet, columnas, vídeo de landing, redes, footer, noticias, tienda y cómo subir imágenes.
- `images/`: imágenes (nombre de archivo en la columna `Image` de la hoja).
- `docs/RECOMMENDATIONS.md`: almacenamiento seguro de imágenes, pipeline y venta online.
